# Cybersecurity Presentations

A collection of cybersecurity presentations developed during university coursework and independent study. The presentations cover **Windows forensics, file-system analysis, anti-forensics, and cybercrime investigations**.

This repository is a presentation archive rather than a lab repository: the slides communicate concepts, investigations, and findings, while detailed technical evidence and practical work are maintained in their respective portfolio repositories.

## Presentations

| Presentation | Work Type | Focus |
|---|---|---|
| [History — File Artifacts in Windows](history-file-artifacts-in-windows.pptx) | Group | Windows file-history artifacts such as recent-files lists, Jump Lists, and ShellBags, with their forensic value |
| [NTFS — A Deep Dive](ntfs-a-deep-dive.pptx) | Group | NTFS internals, file-system structure, the MFT, and relevance to forensic examination |
| [Understanding Anti-Forensics in Cybersecurity](understanding-anti-forensics-in-cybersecurity.pptx) | Solo | Techniques used to hide, wipe, or obscure evidence and the resulting challenges for investigators |
| [Silk Road](silk-road.pptx) | Solo | Investigation and takedown of the Silk Road dark web marketplace |
| [Operation Shrouded Horizon](operation-shrouded-horizon.pptx) | Solo | Law-enforcement takedown of the Darkode cybercrime forum |

## Topics Covered

- Windows forensic artifacts
- NTFS and the Master File Table (MFT)
- Anti-forensics and evidence concealment
- Digital forensics and investigation
- Dark web investigations
- Cybercrime forums and law-enforcement operations
